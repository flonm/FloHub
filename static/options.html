FloHub

A pull request's stack, its reviewers and its versions, on every tab of the pull request.

Pure AI slop. Every line of this extension was generated by an AI coding agent (Claude Code), and no human has reviewed it line by line. It may break whenever GitHub changes its pages. Use it at your own risk.

FloHub can't read github.com or api.github.com yet, so the overview won't appear.

GitHub token

FloHub reads pull requests through GitHub's API with a token of yours. Create one with the right scopes (repo to read pull requests and re-request reviews, read:org to show requested teams) and paste it here.

A fine-grained token instead

Pick the organization as resource owner and grant Pull requests: Read and write, Checks: Read, Commit statuses: Read and optionally Members: Read. Organizations may need to approve it first.

The token is stored only in this browser profile (storage.local) and sent only to api.github.com.

Review requests

A pull request waits for your review when it requests you or one of your teams. In busy repositories, set Only me to see only the pull requests that request you by name. The popup's Hide team requests button on a team request does the same.
