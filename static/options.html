FloHub

Pure AI slop. Every line of this extension was generated by an AI coding agent (Claude Code), and no human has reviewed it line by line. It may break whenever GitHub changes its pages. Use it at your own risk.

Shows a pull request's stack with each layer's status, and every reviewer's verdict with one-click re-request, on every tab.

Shortcuts

  • ⌘⇧↑ / ⌘⇧↓ (Ctrl outside macOS): go to the pull request above / below in the stack
  • R then Y: approve right away, without a comment
  • R then A: approve with a comment
  • R then N: request changes, with or without a comment
  • C then C: copy gh pr checkout <number>
  • C then G: copy the pull request's link

They never fire while you type in a text field. A pending review with draft comments is submitted with your verdict.

Review requests

By default, a pull request waits for your review when it requests you or one of your teams. In busy repositories, set Only me to see only the pull requests that request you by name. The popup's Hide team requests button on a team request does the same.

    FloHub can't read github.com or api.github.com yet, so the overview won't appear.

    Token

    Create a token with the right scopes (repo to read pull requests and re-request reviews, read:org to show requested teams), then paste it below.

    If you prefer a fine-grained token: pick the organization as resource owner and grant Pull requests: Read and write, Checks: Read, Commit statuses: Read and optionally Members: Read. Organizations may need to approve it first.

    The token is stored only in this browser profile (storage.local) and sent only to api.github.com.
